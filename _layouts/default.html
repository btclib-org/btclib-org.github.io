So the copy is gated rather than trusted: `.github/scripts/check-theme-copies.sh` removes every fenced block and compares what is left with the layout in the installed gem, and `website.yml` runs it in the job where bundler has already resolved that gem. A theme upgrade that changes this layout then arrives as a red check on dependabot's own pull request, rather than as a page serving the chrome of a release nobody runs any more.
