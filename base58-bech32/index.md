# base58-bech32

base58-bech32 implements the binary-to-text codecs of cryptocurrency
addresses and keys: Base58, Base58Check, bech32, bech32m, SS58 and CashAddr,
in typed Python.

It imports nothing but the standard library. What the bytes mean is not here:
for bitcoin, that is btclib's.

## Install

```shell
python -m pip install --upgrade base58-bech32
```
