# bbt

bbt is the material of a university course on Bitcoin and blockchain
technology. The repository holds Excel spreadsheets that illustrate finite
fields and elliptic curves, Jupyter notebooks, Python scripts and a regtest lab
for Bitcoin Core. The slides are on the course page.

The course is or has been taught at Università di Milano-Bicocca, Politecnico di
Milano, Università Statale di Milano and ESSEC (Paris). Most of the Python
scripts need btclib.

## Use

Nothing is released: the material is read on GitHub or from a clone.

```shell
git clone https://github.com/btclib-org/bbt.git
```

The scripts print what they compute, keys included, and the lab tutorial
publishes a private key on purpose. Read the README's *Limitations, not
vulnerabilities* before running anything.
