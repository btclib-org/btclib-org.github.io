# bitcoin-core-rpc

bitcoin-core-rpc is a standalone JSON-RPC client against Bitcoin Core, as used
by the btclib library.

It has nothing but the standard library behind it, is fully annotated and ships
`py.typed`. It invokes any one RPC method a node has, with positional or named
parameters.

## Install

```shell
pip install bitcoin-core-rpc
```
