# btclib-mnemonics

btclib-mnemonics implements the mnemonic schemes of bitcoin wallets, BIP39,
SLIP-0039 and Electrum's, from the entropy to the seed, in typed Python.

It imports nothing but the standard library. What a seed derives to is not here:
btclib-wallet is the library above this one.

## Install

```shell
python -m pip install --upgrade btclib-mnemonics
```
