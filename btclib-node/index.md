# btclib-node

btclib-node is a full bitcoin node written in Python and based on btclib.

It is alpha software. Its security policy says what is known before running it,
and the JSON-RPC listener is not something to expose.

## Install

```shell
python -m pip install --upgrade btclib-node
```

The package puts a `btclib-node` command on the path.
