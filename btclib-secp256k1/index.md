# btclib-secp256k1

btclib-secp256k1 is a set of Python bindings to libsecp256k1, Bitcoin Core's
optimized C library for secp256k1.

It signs and verifies with ECDSA and BIP340 Schnorr. Its version numbers track
the libsecp256k1 version it wraps.

## Install

```shell
python -m pip install --upgrade btclib-secp256k1
```
